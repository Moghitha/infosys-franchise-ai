# Milestone 1: Authentication System

## Project Overview
This project implements a secure authentication system using Streamlit. It provides user registration, login, password recovery, email OTP verification, and separate user and admin dashboards.

## Features
- User registration and login
- Password hashing using bcrypt
- JWT-based authentication
- Forgot password using a security question
- Email OTP verification for password recovery
- User dashboard
- Admin dashboard
- SQLite database for storing user information

## Technologies Used
- Python
- Streamlit
- SQLite
- bcrypt
- JSON Web Tokens (JWT)
- SMTP for email OTP delivery
- ngrok for public access during development
- Google Colab for development and execution
